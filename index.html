    ڕێکخستن و کۆپیا پشتەڤانیێ (Backup)

    ئەنجامدانا کۆپیا پشتەڤانیێ یا گشتی بۆ پاراستنا هەمی زانیارییان ژ فەوتانێ

    ڕێکخستنێن سکیوریتی و پاڵپشتیا دۆخێ

    ئەڤ سیستەمە ب شێوازەکێ تەمام لۆکاڵی و سەربەخۆ کار دەکەت. زانیارییێن تە ل سەر فایلا وێبگەڕێ یا ناوخۆیی یا کۆمپیوتەرێ تە پاشکەوت دبن. بۆ ڕێگریکرن ل فەوتانا زانیارییان د دەمێ تێکچوونا کۆمپیوتەرێ تە دا یان سڕینەوەی وێبگەڕەکەت, پێدڤیە ب شێوازەکێ خولی (هەفتانە یان مانگانە) کۆپیا پشتەڤانیێ (Backup) بۆ داتا و فایلێن خۆ دروست بکەی.

    دروستکرنا کۆپیا پشتەڤانیێ (Export Backup)

    هەمی زانیارییێن فەرمانبەران و فۆڵدەرێن PDF دێ هێنە کۆمکرن د ئێک فایلی دا

    زڤڕاندنا فایلا پشتەڤانیێ (Import Backup)

    فایلا پشتەڤانیێ یا پێشتر دەستنیشان بکە بۆ زڤڕاندنا هەمی دۆسیەیان د ئێک چرکە دا

    پشتەڤانیکردنا ئۆنلاین ب Google Drive (Google Drive Cloud Backup)

    گرێدانا سیستەمی ب ئەکاونتێ تە یێ Google Drive بۆ ناردنا کۆپیێن پشتەڤانیێ ب شێوەیەکێ پاراستی و خۆکار بۆ سەر خزمەتگوزارییا هەور (Cloud)، داکو ئەگەر کۆمپیوتەرێ تە تێکچوو یان سووتا، داتایێن تە ل وێرێ د بنەجهـ بمینن.

    بارودۆخێ گرێدانێ: پشکنین دکەت...
    دوماهیک پشتەڤانیکردن: نەکراوە
    چەوانیا دروستکرنا Client ID و Client Secret ل Google Cloud (فێرکاری)
    1. بچۆ سایتێ Google Cloud Console و پڕۆژەیەکێ دروست بکە.
    2. ل بەشێ APIs & Services، ل سەر Library کلیک بکە و Google Drive API چالاک بکە.
    3. بچۆ بەشێ OAuth consent screen، جۆرێ External هەڵبژێرە، پاشان زانیارییێن پڕۆژێ پڕ بکەوە و ل بەشێ Scopes، سکۆپێ .../auth/drive.file زێدە بکە.
    4. پاشان بچۆ بەشێ Credentials، کلیک ل سەر Create Credentials بکە و OAuth client ID هەڵبژێرە.
    5. جۆرێ ئەپلیکەیشنێ بکە ب Web application.
    6. ل خوارێ ل بەشێ Authorized redirect URIs، ئەڤ لینکێ ل خوارێ کۆپی بکە و ل وێرێ زێدە بکە:
      http://localhost:8000/api/gdrive/callback
    7. ل سەر Create کلیک بکە، پاشان Client ID و Client Secret یێن دروستبووی کۆپی بکە و ل ڤان خانەیێن سەرێ بدە.
    بکارئینان ل سەر هێڵا ناوخۆیی (LAN) یان شکست ل گرێدانێ دا:

    ئەگەر تو ب ڕێیا تۆڕەکا ناوخۆیی (IP یەکێ دی وەک 192.168.1.x) ل سیستەمی دکەی یان پشتی گرێدانێ لاپەڕێ سپی هات، لینکێ لاپەڕێ هاتووی ژ سەرێ وێبگەڕێ (URL) کۆپی بکە و ل خوارێ باڤێژە:

    کۆدێ بریکاری (Client ID): ...
